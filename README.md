# test-world

> 🚧 **Work in progress. You're early.**

This repository will contain a minimal VRChat world project used for validating the vrci pipeline.

Every significant change to vrci should successfully build and publish this project before being considered ready for real-world use.

## Planned contents

- Minimal VRChat world
- CI workflows
- Regression testing
- Validation documentation
- Testing against common world frameworks, SDK extensions and tooling.

## Repository status

The test project has not migrated to use vrci yet - it's a legacy project I used with some older solution that no longer works.

It will be migrated and used for testing once the core pipeline is functional.
